# panacea-look

A Claude desktop theme in Panacea Shell's *Nothing* palette: pure black surfaces, white text with grey secondary text, and a single red accent (`#d71921`). Behind the conversation sits a faint dot matrix, echoing the island's dot glyphs, with a soft glow that drifts slowly across it. Dark only, because the look is about black. Applies to Claude Code sessions in the desktop app (the custom-theme feature built on mods).
